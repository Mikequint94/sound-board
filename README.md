# Publizity Soundboard

Simple static soundboard (HTML/CSS/JS). Click the buttons or press the matching keys.

## Run locally

From this folder:

### Python (built-in)

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

### Node (one-off)

```bash
npx serve .
```

## Notes

- Browsers often require a **user gesture** before they’ll play audio, so click/tap once before using keyboard shortcuts.
- **Space** toggles the background beat on/off.
